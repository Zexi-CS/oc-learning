# 计时器程序

> 纯代码 + Masonry，单页面计时器

## 功能

- 黑色背景，上方白色大字计时（`MM:SS` 分:秒）
- 下半区域被两个长方形按钮平分：左边「暂停」（蓝色 + 三角），右边「开始」（绿色 + 两个竖线）
- 暂停后点开始 = 继续计时（不是重新计时）

## 布局

```
┌──────────────────────────────┐
│                              │
│           00:00              │  ← 上半：时间显示（黑色）
│                              │
│──────────────────────────────│ ← 屏幕中线
│              │               │
│   [▶] 暂停   │   [❚❚] 开始    │  ← 下半：两个长方形，各占一半宽
│   （蓝色）   │   （绿色）      │
└──────────────────────────────┘
```

## ② ViewController.m

```objc
#import "ViewController.h"
#import <Masonry/Masonry.h>

@interface ViewController ()
@property (nonatomic, strong) NSTimer *timer;          // 计时器
@property (nonatomic, assign) NSInteger totalSeconds;  // 总秒数
@property (nonatomic, strong) UILabel *timeLabel;      // 时间显示
@end

@implementation ViewController

- (void)viewDidLoad {
    [super viewDidLoad];
    self.view.backgroundColor = [UIColor blackColor];   // 黑色背景
    self.totalSeconds = 0;

    // ---- 上方时间 Label ----
    self.timeLabel = [[UILabel alloc] init];
    self.timeLabel.text = @"00:00";
    self.timeLabel.font = [UIFont systemFontOfSize:72 weight:UIFontWeightLight];
    self.timeLabel.textColor = [UIColor whiteColor];
    self.timeLabel.textAlignment = NSTextAlignmentCenter;
    [self.view addSubview:self.timeLabel];

    // ---- 左下暂停按钮（蓝色 + 三角 ▶）----
    UIButton *pauseBtn = [UIButton buttonWithType:UIButtonTypeCustom];
    pauseBtn.backgroundColor = [UIColor blueColor];
    [pauseBtn setImage:[UIImage systemImageNamed:@"play.fill"] forState:UIControlStateNormal];
    pauseBtn.tintColor = [UIColor whiteColor];
    [pauseBtn addTarget:self action:@selector(pauseClicked) forControlEvents:UIControlEventTouchUpInside];
    [self.view addSubview:pauseBtn];

    // ---- 右下开始按钮（绿色 + 两个竖线 ⏸）----
    UIButton *startBtn = [UIButton buttonWithType:UIButtonTypeCustom];
    startBtn.backgroundColor = [UIColor greenColor];
    [startBtn setImage:[UIImage systemImageNamed:@"pause.fill"] forState:UIControlStateNormal];
    startBtn.tintColor = [UIColor whiteColor];
    [startBtn addTarget:self action:@selector(startClicked) forControlEvents:UIControlEventTouchUpInside];
    [self.view addSubview:startBtn];

    // ---- 约束 ----

    // 时间：上方居中
    [self.timeLabel mas_makeConstraints:^(MASConstraintMaker *make) {
        make.centerX.equalTo(self.view);
        make.top.equalTo(self.view.mas_safeAreaLayoutGuideTop).offset(80);
    }];

    // 暂停按钮：下半区域左半（长方形）
    [pauseBtn mas_makeConstraints:^(MASConstraintMaker *make) {
        make.left.bottom.equalTo(self.view);
        make.top.equalTo(self.view.mas_centerY);
        make.width.equalTo(self.view).multipliedBy(0.5);
    }];

    // 开始按钮：下半区域右半（长方形，紧贴暂停右边）
    [startBtn mas_makeConstraints:^(MASConstraintMaker *make) {
        make.left.equalTo(pauseBtn.mas_right);
        make.right.bottom.equalTo(self.view);
        make.top.equalTo(self.view.mas_centerY);
    }];
}

// ---- 开始按钮 ----
- (void)startClicked {
    if (self.timer) {                 // 防止连点产生多个计时器
        [self.timer invalidate];
        self.timer = nil;
    }
    self.timer = [NSTimer scheduledTimerWithTimeInterval:1.0
                                                  target:self
                                                selector:@selector(tick)
                                                userInfo:nil
                                                 repeats:YES];
}

// ---- 暂停按钮 ----
- (void)pauseClicked {
    [self.timer invalidate];
    self.timer = nil;                 // totalSeconds 不清零 → 暂停后点开始是"继续"计时
}

// ---- 每秒触发 ----
- (void)tick {
    self.totalSeconds++;
    NSInteger minutes = self.totalSeconds / 60;   // 整除 → 分钟
    NSInteger seconds = self.totalSeconds % 60;   // 取余 → 秒
    self.timeLabel.text = [NSString stringWithFormat:@"%02ld:%02ld", (long)minutes, (long)seconds];
}

// ---- 解决循环引用：页面离开时主动断环 ----
- (void)viewWillDisappear:(BOOL)animated {
    [super viewWillDisappear:animated];
    [self.timer invalidate];
    self.timer = nil;
}

@end
```

## ③ SceneDelegate.m（设置根控制器）

单页面计时器不需要跳转，根控制器**直接设 ViewController**，不用包导航控制器。

```objc
#import "SceneDelegate.h"
#import "ViewController.h"

@implementation SceneDelegate

- (void)scene:(UIScene *)scene
    willConnectToSession:(UISceneSession *)session
                 options:(UISceneConnectionOptions *)connectionOptions {

    UIWindowScene *windowScene = (UIWindowScene *)scene;
    self.window = [[UIWindow alloc] initWithWindowScene:windowScene];

    // 单页面，直接设为根控制器
    self.window.rootViewController = [[ViewController alloc] init];

    [self.window makeKeyAndVisible];
}

@end
```

## 关键知识点

### 1. NSTimer 循环引用

`target:self` 会循环引用：

```
VC ──self.timer(strong)──→ timer
 ↑                          │
 └────target:self(strong)───┘
```

**后果：** VC 无法释放，`dealloc` 不会被调用，timer 一直跑。

**解决：** 在 `viewWillDisappear` 里 `invalidate + 置 nil`。⚠️ **不能在 dealloc 里做**（循环引用导致 dealloc 根本不会调）。

### 2. 长方形平分下半区域

- 暂停按钮：`width = 屏幕 × 0.5`（`multipliedBy(0.5)`），占左半
- 开始按钮：`left = 暂停.right`，占右半
- 两者 `top = mas_centerY`（屏幕中线），高度正好是屏幕的一半

### 3. 分:秒换算

```objc
minutes = totalSeconds / 60;   // 整除算分钟
seconds = totalSeconds % 60;   // 取余算秒
```

`%02ld` 格式化补零（`01:05` 这种）。

## 运行前提

1. **CocoaPods 装 Masonry**（Podfile）：
```ruby
pod 'Masonry'
```
2. **纯代码项目**：删掉 Main.storyboard 文件 + Info.plist 里的 "Main storyboard file base name" 配置
3. 图标用 SF Symbol（`play.fill`、`pause.fill`），需 iOS 13+；跑不了就换成 `setTitle:@"▶"` / `setTitle:@"❚❚"`
