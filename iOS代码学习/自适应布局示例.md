# 自适应布局示例（标题 + 三个灰色方块 + 图片）

> 横竖屏自适应，纯代码 + Masonry，已考虑安全区

---

## 目标布局

```
┌─────────────────────────┐
│        标题 Label        │  ← 顶部居中（避开顶部安全区）
│                          │
│  [灰块] [灰块] [灰块]     │  ← 中间，等大，间距均匀（避开左右安全区）
│                          │
│        [图片]            │  ← 底部居中
└─────────────────────────┘
```

---

## 完整代码（ViewController.m）

```objc
#import "ViewController.h"
#import <Masonry/Masonry.h>

@implementation ViewController

- (void)viewDidLoad {
    [super viewDidLoad];
    self.view.backgroundColor = [UIColor whiteColor];

    // ============================================================
    // 1. 标题 Label
    // ============================================================
    UILabel *titleLabel = [[UILabel alloc] init];
    titleLabel.text = @"标题";
    titleLabel.textAlignment = NSTextAlignmentCenter;
    titleLabel.font = [UIFont boldSystemFontOfSize:20];
    [self.view addSubview:titleLabel];

    // ============================================================
    // 2. 三个灰色方块（用 UIView，纯展示不点击）
    // ============================================================
    UIView *block1 = [[UIView alloc] init];
    block1.backgroundColor = [UIColor lightGrayColor];

    UIView *block2 = [[UIView alloc] init];
    block2.backgroundColor = [UIColor lightGrayColor];

    UIView *block3 = [[UIView alloc] init];
    block3.backgroundColor = [UIColor lightGrayColor];

    [self.view addSubview:block1];
    [self.view addSubview:block2];
    [self.view addSubview:block3];

    // ============================================================
    // 3. 图片 ImageView
    // ============================================================
    UIImageView *imageView = [[UIImageView alloc] init];
    imageView.image = [UIImage imageNamed:@"你的图片名"];
    imageView.contentMode = UIViewContentModeScaleAspectFit;   // 等比缩放不变形
    [self.view addSubview:imageView];

    // ============================================================
    // 4. 设约束（从上到下：标题 → 方块 → 图片，全考虑安全区）
    // ============================================================

    // --- 标题：顶部居中（顶部安全区） ---
    [titleLabel mas_makeConstraints:^(MASConstraintMaker *make) {
        make.top.equalTo(self.view.mas_safeAreaLayoutGuideTop).offset(30);  // 距顶部安全区 30
        make.centerX.equalTo(self.view);                                    // 水平居中
    }];

    // --- 方块1：靠左，在标题下方（左侧安全区） ---
    [block1 mas_makeConstraints:^(MASConstraintMaker *make) {
        make.left.equalTo(self.view.mas_safeAreaLayoutGuideLeft).offset(20); // 距左侧安全区 20
        make.top.equalTo(titleLabel.mas_bottom).offset(50);                  // 标题下方 50
        make.height.mas_equalTo(80);                                         // 高 80
    }];

    // --- 方块2：在方块1右边，等大等间距 ---
    [block2 mas_makeConstraints:^(MASConstraintMaker *make) {
        make.left.equalTo(block1.mas_right).offset(15);   // 方块1右边 15
        make.top.equalTo(block1);                         // 顶部对齐方块1
        make.width.equalTo(block1);                       // 宽 = 方块1（等宽）
        make.height.equalTo(block1);                      // 高 = 方块1（等高）
    }];

    // --- 方块3：在方块2右边靠右，等大等间距（右侧安全区） ---
    [block3 mas_makeConstraints:^(MASConstraintMaker *make) {
        make.left.equalTo(block2.mas_right).offset(15);                       // 方块2右边 15
        make.right.equalTo(self.view.mas_safeAreaLayoutGuideRight).offset(-20); // 距右侧安全区 20
        make.top.equalTo(block1);                                            // 顶部对齐方块1
        make.width.equalTo(block1);                                          // 等宽
        make.height.equalTo(block1);                                         // 等高
    }];

    // --- 图片：方块下方，居中 ---
    [imageView mas_makeConstraints:^(MASConstraintMaker *make) {
        make.centerX.equalTo(self.view);                  // 水平居中
        make.top.equalTo(block1.mas_bottom).offset(50);   // 方块下方 50
        make.width.mas_equalTo(150);                      // 宽 150
        make.height.mas_equalTo(150);                     // 高 150
    }];
}

@end
```

---

## 关键点总结

### 1. 三个方块"等大 + 间距均匀"

```objc
方块2、3 用 make.width.equalTo(block1) 和 make.height.equalTo(block1) 绑定到方块1
方块1 靠左，方块3 靠右，中间固定间距 15 → 三个等宽自动铺满
```

### 2. 方块放"标题和图片中间"

```objc
方块.top = 标题.bottom + 50    （方块在标题下面）
图片.top = 方块.bottom + 50    （图片在方块下面）
```
链式约束把三者从上到下串起来。

### 3. 安全区（横竖屏都安全）

| 元素靠哪边 | 用哪个 |
|---|---|
| 标题靠顶部 | `mas_safeAreaLayoutGuideTop` |
| 方块靠左 | `mas_safeAreaLayoutGuideLeft` |
| 方块靠右 | `mas_safeAreaLayoutGuideRight` |
| 图片居中 | 不需要安全区 |

**口诀：靠屏幕哪边，就用哪边的安全区；居中就不用管。**

### 4. 为什么横竖屏自适应

全部用相对约束（居中、等宽、距安全区），没有写死坐标，横竖屏切换时约束自动重新计算。

## 灰色方块用 Button 还是 View？

| 情况 | 用哪个 |
|---|---|
| 方块要点击（功能入口） | UIButton |
| 方块纯展示（装饰色块） | UIView |

本示例是纯展示，所以用 UIView。若要点击，把 `UIView *block1 = [[UIView alloc] init]` 换成 `UIButton *block1 = [UIButton buttonWithType:UIButtonTypeCustom]` 即可，约束不变。

## 更简洁的替代：UIStackView

三个等大方块均匀分布，用 StackView 一行搞定：

```objc
UIStackView *stack = [[UIStackView alloc] init];
stack.axis = UILayoutConstraintAxisHorizontal;              // 横向排列
stack.spacing = 15;                                         // 间距 15
stack.distribution = UIStackViewDistributionFillEqually;    // 等宽

[stack addArrangedSubview:block1];
[stack addArrangedSubview:block2];
[stack addArrangedSubview:block3];
[self.view addSubview:stack];

[stack mas_makeConstraints:^(MASConstraintMaker *make) {
    make.left.equalTo(self.view.mas_safeAreaLayoutGuideLeft).offset(20);
    make.right.equalTo(self.view.mas_safeAreaLayoutGuideRight).offset(-20);
    make.top.equalTo(titleLabel.mas_bottom).offset(50);
    make.height.mas_equalTo(80);
}];
```
