## 程序一：通知程序（NSNotificationCenter）

**功能**：Boy 吃完饭后发一条通知，Girl 收到通知后自动去吃饭 —— 这是 OC 里 **通知中心广播** 的完整演示（发通知 / 收通知 / 注销监听）。

**来源路径**：
`C:\Users\admin\WorkBuddy\17-OC基础巩固_通知协议Block\`
- `Boy.h` / `Boy.m`（发通知方）
- `Girl.h` / `Girl.m`（收通知方）
- `main.m`（入口测试）

### 1. 定义通知频道名 —— `Boy.m` 顶部

```objc
// ===== ① 定义通知的名字（相当于广播的频道）=====
NSString *const kSomeoneAteNotification = @"kSomeoneAteNotification";
```

### 2. 发通知方 —— `Boy.m`

```objc
#import "Boy.h"

@implementation Boy

- (void)eatSomething {
    NSLog(@"Boy：我在吃饭 🍚");

    // ===== ② 吃完饭，发一条通知 =====
    [[NSNotificationCenter defaultCenter] postNotificationName:kSomeoneAteNotification
                                                        object:self];
    //                                   ^^^^^^^^^^^^^^^^^^^^     ^^^^
    //                                   在哪个频道喊               谁喊的（Boy自己）
}

@end
```

### 3. 收通知方 —— `Girl.m`

```objc
#import "Girl.h"

// ===== ③ 告诉编译器：kSomeoneAteNotification 在 Boy.m 里定义好了 =====
extern NSString *const kSomeoneAteNotification;

@implementation Girl

- (instancetype)init {
    self = [super init];
    if (self) {
        // ===== ④ Girl 一出生就开始"收听广播" =====
        [[NSNotificationCenter defaultCenter] addObserver:self
                                                 selector:@selector(eatSomething)
                                                     name:kSomeoneAteNotification
                                                   object:nil];
        //        ^^^^^^^^^^^^^^^^^^^^^^^^^^^^     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
        //         "频道" = Boy 发的那条            nil = 不管谁发的都收
    }
    return self;
}

// ===== ⑤ 收到通知后执行这个方法 =====
- (void)eatSomething {
    NSLog(@"Girl：我也在吃饭 🍜");
}

// ===== ⑥ 销毁前取消收听（不然通知中心找不到了，会崩溃）=====
- (void)dealloc {
    [[NSNotificationCenter defaultCenter] removeObserver:self];
}

@end
```

### 4. 入口测试 —— `main.m`

```objc
#import <Foundation/Foundation.h>
#import "Boy.h"
#import "Girl.h"

int main(int argc, const char * argv[]) {
    @autoreleasepool {
        Girl *girl = [[Girl alloc] init];   // Girl 出生 → init 里开始收听通知
        Boy  *boy  = [[Boy alloc] init];    // Boy 出生

        [boy eatSomething];                 // 只让 Boy 吃

        // 运行输出：
        // Boy：我在吃饭 🍚
        // Girl：我也在吃饭 🍜
    }
    return 0;
}
```

### 通知机制要点（源自笔记）
```
发通知 → 通知中心广播 → 所有听众收到 → 自动执行注册的方法
```
- 发通知：`postNotificationName:object:`（可带 `userInfo:` 传数据）
- 收通知：`addObserver:selector:name:object:`（init 中注册）
- 注销：`dealloc` 中必须 `removeObserver:`，否则野指针崩溃
- 频道名用 `NSString *const` 全局常量 + `extern` 跨文件引用

## 程序二：用分类返回字符串是否包含数字

**功能**：给系统类 **NSString** 添加分类方法，判断字符串里是否包含数字（返回 BOOL）。这是学习 OC **分类（Category）** 时的实践。

**事实说明**：
- 该方法**没有独立的 .h/.m 源码文件**，代码思路完整记录在笔记 `OC基础笔记.md` 的「十、分类」和「十一、NSCharacterSet」小节，以及 7-21 日志与周报中均记录了 `isEmpty / hasNumber` 实践。
- 下方已整理成可直接使用的完整分类文件代码。

### 完整分类代码（可新建 NSString+Valid.h/.m 直接使用）

**`NSString+Valid.h`（声明）**

```objc
//
//  NSString+Valid.h
//  给 NSString 扩展"校验"方法
//
#import <Foundation/Foundation.h>

@interface NSString (Valid)     // 括号里命名分类名

/// 是否为空串（nil / 空字符串）
- (BOOL)isEmpty;

/// 是否包含数字（0-9）
- (BOOL)hasNumber;

@end
```

**`NSString+Valid.m`（实现）**

```objc
//
//  NSString+Valid.m
//
#import "NSString+Valid.h"

@implementation NSString (Valid)

// 判断是否为空：length == 0 同时覆盖了 nil 和 @""
- (BOOL)isEmpty {
    return self.length == 0;
}

// 判断字符串里是否含有数字字符（0-9）
- (BOOL)hasNumber {
    // decimalDigitCharacterSet = 数字字符集 {0,1,2,...,9}
    NSCharacterSet *digitSet = [NSCharacterSet decimalDigitCharacterSet];

    // 在整个字符串里找第一个数字字符的位置
    // 找到返回非 NSNotFound，找不到返回 NSNotFound
    NSRange r = [self rangeOfCharacterFromSet:digitSet];

    // 位置不是 NSNotFound → 说明有数字 → 返回 YES
    return r.location != NSNotFound;
}

@end
```

**使用示例**

```objc
#import "NSString+Valid.h"

[@"abc" isEmpty];            // NO（有内容）
[@""    isEmpty];            // YES（空串）

[@"Hello123" hasNumber];     // YES（包含数字 1、2、3）
[@"Hello"    hasNumber];     // NO（不含数字）
```

### hasNumber 的判断原理（源自笔记「十一、常用工具方法」）

```objc
// NSCharacterSet 常用字符集
[NSCharacterSet decimalDigitCharacterSet]          // 数字 0-9
[NSCharacterSet letterCharacterSet]                // 字母 a-z A-Z

// 判断字符串里有没有数字：
NSRange r = [str rangeOfCharacterFromSet:[NSCharacterSet decimalDigitCharacterSet]];
BOOL hasNumber = (r.location != NSNotFound);
```

### 分类（Category）要点
- 不改原文件，给已有类（含系统类如 NSString）**新增方法**
- 文件命名：`原类名+分类名.h`，如 `NSString+Valid.h`
- 限制：**能加方法，不能加成员变量**（写了 @property 也不会自动生成存取器）
