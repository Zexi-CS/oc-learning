## 一、NetworkManager.h — 新增下载声明

在头文件末尾加：

```objc
#pragma mark - 文件下载

/// 下载进度回调（progress: 0.0 ~ 1.0）
typedef void (^DownloadProgressBlock)(double progress);

/// 下载完成回调（filePath: 文件保存路径）
typedef void (^DownloadCompletionBlock)(BOOL success, NSString * _Nullable filePath, NSError * _Nullable error);


/// 5. NSURLSessionDownloadTask 下载文件（带进度 + 保存到沙盒 Documents）
- (void)downloadFileFromURL:(NSString *)urlString
                   progress:(DownloadProgressBlock _Nullable)progressBlock
                 completion:(DownloadCompletionBlock)completion;
```

和之前的 `NetworkCompletionBlock` 一样，用 `typedef` 给两个 Block 类型起别名。区别是 `DownloadProgressBlock` 在下载过程中被反复调用（每次更新进度），不是只调一次。

## 二、 NetworkManager.m — 新增下载实现

### 2.1 私有属性扩展

在 `@interface NetworkManager ()` 扩展里加：

```objc
@interface NetworkManager () <NSURLSessionDownloadDelegate>
//                            ↑ ★ 实现下载代理协议，才能接收进度回调

@property (nonatomic, strong) NSURLSession *session;
@property (nonatomic, strong) NSURLSession *downloadSession;  // 下载专用 session

// 下载回调和数据临时存储
@property (nonatomic, copy) DownloadProgressBlock downloadProgressBlock;
@property (nonatomic, copy) DownloadCompletionBlock downloadCompletionBlock;
@property (nonatomic, strong) NSData *downloadResumeData;     // 断点续传数据

@end
```

### 2.2 修改 `initPrivate` 方法

把原来的空实现改成创建两个 session：

```objc
- (instancetype)initPrivate {
    self = [super init];
    if (self) {
        // ─── 普通请求 session（GET/POST/修改/删除）───
        NSURLSessionConfiguration *config = [NSURLSessionConfiguration defaultSessionConfiguration];
        config.timeoutIntervalForRequest = 30.0;
        _session = [NSURLSession sessionWithConfiguration:config];

        // ─── 下载专用 session（必须设 delegate = self） ─── 
        NSURLSessionConfiguration *downloadConfig = [NSURLSessionConfiguration defaultSessionConfiguration];
        downloadConfig.timeoutIntervalForRequest = 60.0;   // 下载超时给久一点
        _downloadSession = [NSURLSession sessionWithConfiguration:downloadConfig
                                                         delegate:self    // ★ self 作为代理
                                                    delegateQueue:[NSOperationQueue mainQueue]];
    }
    return self;
}
```

**关键：** 普通 session 不需要 delegate ＝ 用系统默认回调（completionHandler Block）。下载 session **必须设 delegate**，否则收不到进度回调。这两个 session 是独立的。

### 2.3 修改四个接口方法，用 `self.session` 替代 `[NSURLSession sharedSession]`

把之前四个方法里的：

```objc
NSURLSession *session = [NSURLSession sharedSession];
```

全部改成：

```objc
// 直接用单例里创建好的 session，不用每次都临时建
NSURLSessionDataTask *task = [self.session dataTaskWithRequest:request ...];
```

这样所有请求共用同一个 session，效率更高。



### 2.4 下载方法实现

```objc
#pragma mark - 5. 下载文件（NSURLSessionDownloadTask）

- (void)downloadFileFromURL:(NSString *)urlString
                   progress:(DownloadProgressBlock)progressBlock
                 completion:(DownloadCompletionBlock)completion {

    // 存好回调 Block，因为进度和完成是不同时间触发的
    self.downloadProgressBlock = progressBlock;
    self.downloadCompletionBlock = completion;

    NSURL *url = [NSURL URLWithString:urlString];
    NSLog(@"[下载] 开始下载：%@", urlString);

    // ★ 创建下载任务（和 dataTask 不同，不需要传 request，直接传 URL）
    NSURLSessionDownloadTask *downloadTask = [self.downloadSession downloadTaskWithURL:url];
    [downloadTask resume];
}


#pragma mark - NSURLSessionDownloadDelegate（下载进度监听）

// ★ 下载进度回调 — 下载过程中反复调用 ★
- (void)URLSession:(NSURLSession *)session
      downloadTask:(NSURLSessionDownloadTask *)downloadTask
      didWriteData:(int64_t)bytesWritten              // 本次写了多少
 totalBytesWritten:(int64_t)totalBytesWritten          // 已经写了多少
totalBytesExpectedToWrite:(int64_t)totalBytesExpectedToWrite {  // 总共多少

    if (totalBytesExpectedToWrite <= 0) return;   // 获取不到总大小，跳过

    double progress = (double)totalBytesWritten / (double)totalBytesExpectedToWrite;

    NSLog(@"[下载进度] %.1f%%", progress * 100);

    if (self.downloadProgressBlock) {
        self.downloadProgressBlock(progress);
    }
}


// ★ 下载完成回调 — 文件在临时目录，需要移到 Documents ★
- (void)URLSession:(NSURLSession *)session
      downloadTask:(NSURLSessionDownloadTask *)downloadTask
didFinishDownloadingToURL:(NSURL *)location {
    //    ↑
    //    location 是系统临时文件夹的路径（随时会被清理）

    // ---- 1. 获取文件名 ----
    NSHTTPURLResponse *httpResponse = (NSHTTPURLResponse *)downloadTask.response;
    NSString *filename = nil;

    // 优先从 Content-Disposition 响应头里提取文件名
    NSString *contentDisposition = httpResponse.allHeaderFields[@"Content-Disposition"];
    if (contentDisposition) {
        NSRange range = [contentDisposition rangeOfString:@"filename="];
        if (range.location != NSNotFound) {
            filename = [contentDisposition substringFromIndex:range.location + range.length];
            filename = [filename stringByReplacingOccurrencesOfString:@"\"" withString:@""];
            filename = [filename stringByTrimmingCharactersInSet:[NSCharacterSet whitespaceAndNewlineCharacterSet]];
        }
    }

    // 备选：从 URL 最后一段取文件名
    if (!filename.length) {
        filename = downloadTask.response.suggestedFilename;
    }

    // 兜底：时间戳文件名
    if (!filename.length) {
        filename = [NSString stringWithFormat:@"download_%@.file", @([[NSDate date] timeIntervalSince1970])];
    }

    NSLog(@"[下载完成] 文件名：%@", filename);

    // ---- 2. 移动到沙盒 Documents ----
    NSString *documentsPath = [NSSearchPathForDirectoriesInDomains(
        NSDocumentDirectory, NSUserDomainMask, YES) firstObject];
    NSString *destPath = [documentsPath stringByAppendingPathComponent:filename];

    NSFileManager *fm = [NSFileManager defaultManager];
    if ([fm fileExistsAtPath:destPath]) {
        [fm removeItemAtPath:destPath error:nil];   // 同名文件先删掉
    }

    NSError *moveError = nil;
    if ([fm moveItemAtURL:location toURL:[NSURL fileURLWithPath:destPath] error:&moveError]) {
        NSLog(@"========================================");
        NSLog(@"[文件保存成功] 路径：%@", destPath);
        NSLog(@"========================================");

        if (self.downloadCompletionBlock) {
            self.downloadCompletionBlock(YES, destPath, nil);
        }
    } else {
        NSLog(@"[文件保存失败] %@", moveError.localizedDescription);

        if (self.downloadCompletionBlock) {
            self.downloadCompletionBlock(NO, nil, moveError);
        }
    }

    // 用完后清空，防止循环引用
    self.downloadProgressBlock = nil;
    self.downloadCompletionBlock = nil;
}


// ★ 下载出错回调 ★
- (void)URLSession:(NSURLSession *)session
              task:(NSURLSessionTask *)task
didCompleteWithError:(NSError *)error {

    if (error) {
        NSLog(@"[下载失败] %@", error.localizedDescription);

        // 保存断点续传数据（可选）
        NSData *resumeData = error.userInfo[NSURLSessionDownloadTaskResumeData];
        if (resumeData) {
            self.downloadResumeData = resumeData;
            NSLog(@"[下载中断] 已保存断点续传数据");
        }

        if (self.downloadCompletionBlock) {
            dispatch_async(dispatch_get_main_queue(), ^{
                self.downloadCompletionBlock(NO, nil, error);
            });
        }
    }

    self.downloadProgressBlock = nil;
    self.downloadCompletionBlock = nil;
}
```

## 三、下载流程解析

```
DataTask（GET/POST）           vs          DownloadTask（下载）

创建：dataTaskWithRequest:        →    downloadTaskWithURL:
回调：completionHandler一次性     →    delegate分阶段：
                                          • didWriteData — 反复调（进度）
                                          • didFinishDownloading — 调一次（完成）
                                          • didCompleteWithError — 调一次（出错）
结果：NSData 内存在内存里         →    文件存在临时目录（大文件不会爆内存）
```

**沙盒 Documents 路径：**

```
NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, ...)
    ↓
/var/mobile/Containers/Data/Application/XXXXXX/Documents/
                                                    ↓
                                           download_xxx.png
    每个 App 有自己的沙盒，改名后下一个 App 看不到你的文件
```

## 四、SceneDelegate — 入口配置

> iOS 13 起用 SceneDelegate 接管窗口创建。直接把下面的代码写入 Xcode 自动生成的 SceneDelegate.m。

```objc
//
//  SceneDelegate.m
//

#import "SceneDelegate.h"
#import "UserListViewController.h"

@implementation SceneDelegate

- (void)scene:(UIScene *)scene willConnectToSession:(UISceneSession *)session
      options:(UISceneConnectionOptions *)connectionOptions {

    UIWindowScene *windowScene = (UIWindowScene *)scene;

    // 1. 创建 window（和 windowScene 关联）
    self.window = [[UIWindow alloc] initWithWindowScene:windowScene];
    self.window.frame = [UIScreen mainScreen].bounds;

    // 2. 创建主页
    UserListViewController *vc = [[UserListViewController alloc] init];

    // 3. 包进导航控制器（这样 self.title 才能显示，右上角按钮才能出现）
    UINavigationController *nav = [[UINavigationController alloc] initWithRootViewController:vc];

    // 4. 设为根视图
    self.window.rootViewController = nav;

    // 5. 显示
    [self.window makeKeyAndVisible];
}

@end
```

AppDelegate 保持默认不要动，不用改任何东西。窗口创建全在 SceneDelegate 里完成。

## 五、Info.plist — ATS 配置

在 Info.plist 里加这个片段（允许 HTTP 明文请求）：

```xml
<key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowsArbitraryLoads</key>
    <true/>
</dict>
```

**为什么必须加？** iOS 默认禁止 HTTP（只允许 HTTPS）。我们的服务器地址是 `http://10.17.66.196:8086`，不加这段代码所有网络请求全部失败。
